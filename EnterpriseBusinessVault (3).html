White Cat Red Rose enhanced RSE filehealing · NULLNX-RSE · core 252

Real GF(256) Reed-Solomon erasure coding. A vault file is cut into k data shards plus m parity shards and written to shards/<file>/. Any k of the k+m shards rebuild the file exactly. "Delete" and "Corrupt" act on the real shard files on disk; Heal reads what survives (each shard carries its own checksum, so damaged ones count as lost), rebuilds every missing shard, and restores the vault file itself if it is gone or damaged. Shards are pieces of the already-encrypted container, so they never expose plaintext.

Freshness & Integrity

On a real interval every file in files/ is decrypted (AES-GCM tag checked), CRC32-verified, then re-encrypted with a fresh IV and refreshed key-recovery blocks and written back in place (its shard set is rebuilt to match). 24 hours is a common convention, not a universal standard; it is configurable.

Ground Control signal-agnostic (sim / serial / websocket) · drone-agnostic framing

Every drone has its own pairing key, link, sequence counter and telemetry. A frame signed with one drone's key fails every other drone's check, so drones can share a channel without acting on each other's commands. Select a drone to work with it below; the buttons at the bottom go to every connected drone.

Frame: A5 | LEN | SEQ(2) | TYPE | PAYLOAD | TAG(8), TAG = HMAC-SHA256 (pairing key) over everything before it. Every byte is sent as two Hamming(8,4) codewords: one flipped bit per codeword is corrected, two are detected and the frame dropped; anything that slips through fails the tag. SEQ must strictly increase, so replays are refused. This is a custom protocol, not tied to any one drone's native language, and it doesn't care whether the bytes travel over the simulator, a serial radio, or a WebSocket bridge — swap the link, keep the same authentication. The pairing key lives sealed in drone/. Telemetry carries position (lat/lon) and a 16-bit heading, and a GOTO command (type 22) flies the simulated drone to a point you click on the map, inside a 3 km fence around home.
Honest limit: the simulator is fully exercised. Serial/WebSocket links carry these same bytes to a companion radio or firmware that speaks this exact protocol, and are untested against real hardware — test props-off or tethered.
